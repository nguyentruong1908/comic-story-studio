# Shared production contract

Read once per chapter or changed workflow. Load a domain reference only when that operation needs its schema; do not reload all skills/references for every page. Default production scope is finished comic artwork and its source/identity/provenance/independent native QA metadata. CMS ingestion, database/CDN storage, reader UI, browser/mobile presentation and deployment are a separate delivery workflow, invoked only when requested.

## Invariants

- Read workspace/series instructions and resolve the current plan/resources through `series.json`. Preserve source bytes, scope, stable identities and frozen job inputs. Root alone promotes canonical files. Context/hash validation is not semantic or pixel approval.
- Only Codex image_gen creates or changes canonical art, references, lettering, balloons and effects. After canonical art QA, the explicitly approved reader-delivery step may create a separate `mobile-extreme` derivative at `448x672`; it must record source/derivative hashes and never overwrite canonical bytes. All other code may inspect metadata, hash and copy unchanged bytes. Record genuine arguments, original output/hash, actual clocks and limitations; never fabricate provenance or review. See [imagegen-only.md](imagegen-only.md) for the canonical provenance schema.
- Analyze every canonical paragraph/clause, dialogue, thought, description, uncertainty and consequence. Independently review decomposition and every final carrier. Audit units are not layout units: several units may share a panel or natural balloon with exact fragment offsets. Show allowed content directly; adapt only the specifically prohibited element while preserving facts and stakes. See [paragraph-completeness.md](paragraph-completeness.md).
- Before render, approve scoped research, individual character references, necessary asset references, distinctiveness and storyboard. Freeze hashes and the actual preflight start. Source outranks adaptations; choice and inference stay labelled. Refresh changed design/scope, not unchanged evidence indiscriminately. See [research-world-style.md](research-world-style.md).
- Plan actual visible cast/assets, speakers, source realizations, current physical state, action/contact/consequence and facial/body cues. Identity does not lock a neutral pose. Motion/crowd contracts apply where the scene requires them; report disabled historical contracts as SKIP. See [action-expression.md](action-expression.md).
- Reconcile each speech carrier with a visible speaking mouth or an explicitly offscreen/occluded speaker before image_gen. A prompt that labels a character as speaking while also requiring a closed-mouth aftermath state is contradictory and must be split or clarified from the source chronology before rendering.
- Treat speech-mouth contradictions and over-dense panels as blocking pre-render metadata findings: require `speech_mouth_phase: open` (or explicit offscreen/occluded attribution), keep any closed-mouth reaction in a later phase, and expand or split text zones at source-unit boundaries when density exceeds the layout limit. Preserve every source word and carrier.
- Every final page receives independent native original-pixel/source/reference inspection, with all required art review domains bound to current bytes. One reviewer may record all domains in one report. An edit invalidates that page's pixel evidence; recheck it and affected adjacent transitions. Reuse unchanged page evidence only with identical image/reference hashes and applicable scope. Browser/mobile checks are not production prerequisites; record genuinely unperformed delivery checks as deferred, never PASS. Legacy delivery gates retain their behavior unless an explicit authorized art-production scope is selected. Never substitute metadata PASS for inspected pixels. See [qa-gates.md](qa-gates.md).
- Run one complete blocking QA entrypoint for the current input tuple. `qa_chapter.mjs` is a compatibility wrapper, not a second independent audit. Additional validators serve diagnostics; rerun the full gate after relevant inputs change. All required gates still pass before publication.
- Human review status remains truthful. Honor explicit review deferral; it waives waiting, never internal art QA. A production chapter completes after the required art gates; it need not be published. When publication is requested separately, deliver eligible reviewed bytes with verified destination hashes and the requested reader/CMS checks.

## Work and storage

Keep one canonical plan, analysis, storyboard and manifest. Reference immutable call/review records by path/hash; avoid embedding the same dossier or arguments in multiple views. Retain actual originals and required evidence. Use compact reversible metadata journals between meaningful phase checkpoints; do not duplicate a complete manifest after each page merge. [metadata_history.py](../scripts/metadata_history.py) records semantic changes with raw-hash provenance; replay restores JSON meaning, not original formatting. Preserve exact byte checkpoints referenced by frozen jobs, approvals, full-gate or publication receipts. Legacy helpers keep snapshot behavior unless `--compact-history` is explicitly enabled for progress transitions whose consumers support semantic rollback; never silently convert existing required checkpoints.

Review original images directly; art production needs no HTML QA routes or copied reader image galleries. Share already-viewed references within a reviewer session; reopen changed or ambiguous material. Do not emit base64 to text logs or repeatedly redisplay unchanged galleries. Clean only verified rebuildable copies with authorization; retain originals and provenance. Keep an immutable selected-asset inventory for later CMS/database/CDN ingestion without assuming images reside in web source. If a local reader publication is separately requested, create the verified `mobile-extreme` derivative first, then use [build_reader_manifest.mjs](../scripts/build_reader_manifest.mjs) after its full delivery gates, keeping the canonical audit dossier and originals internal.

Each work batch reports completed outputs, real failures, next action, calls/repairs and space used. A recurring defect needs a prompt/reference/root-cause correction before more copies of the same scene. After two unsuccessful targeted repairs, diagnose the invariant and involve another reviewer; do not silently accept the defect or repeat identical edits indefinitely.
