# World and Visual Research

Follow the [shared contract](../../references/production-contract.md); read [research-world-style](../../references/research-world-style.md) for dossier fields and evidence.

Read canon first. Research unresolved era, role, costume, location/function or material questions through official/primary sources. Use web tools for ordinary research; browser fallback only for indispensable unavailable visual evidence. Open the source, distinguish text from inspected pixels, and record access limits.

Produce one scoped dossier with evidence-linked facts, design choices, conflicts and concrete briefs. Adaptations never override current canon or reveal future costumes/events. Reuse verified unchanged research; refresh only changed scope, weak evidence or genuinely new questions. Avoid a new research report for every ordinary prop or chapter when existing evidence suffices.

Review source applicability and visual specificity, run `validate_research_context.mjs --research-only`, then hand off current hashes and concise relevant cues. The structural gate validates records, not truth or visual quality. Reference art starts only after this gate passes.
