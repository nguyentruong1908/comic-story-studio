# Storyboard Planning

Follow the [shared contract](../../references/production-contract.md). Read [paragraph completeness](../../references/paragraph-completeness.md); use [manifest contract](../../references/manifest-contract.md), [action/expression](../../references/action-expression.md) and motion guidance only for applicable scenes.

Build from reviewed analysis/references. Group source units sharing time, actor, action and setting into natural moments; one unit is not one panel/page. Preserve every fact and exact dialogue, using several exact fragment offsets in one balloon when appropriate. Do not set a fixed two-panel ceiling or min-art-height rule that forces a caption fragment onto a separate page. Choose page count after mobile-readable layout and narrative coverage; add space where actual dialogue/acting needs it.

Each page has a dominant beat, entry/exit state and causal neighbor link. Each panel has a concrete shot/action, actual visible cast/assets, current state, source realizations, source-backed introductions, speakers/tails/reading order and acting cues. Specify background only to the extent it is shown. Keep full object histories in the ledger; never paste historical/future actions as current shot commands.

Before render run source coverage (`--design-only --require-enabled`), action/expression (`--design-only --require-enabled`), research context and applicable crowd/motion design gates, then story fidelity after recording the actual preflight clock. Metadata checks do not approve pixels. Review density, chronology and complete source coverage independently before freeze.
